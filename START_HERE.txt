🤖 INTELLIGENT WEB SCRAPER WITH LLM AGENT
==========================================

✓ COMPLETE & READY FOR TESTING

What This Project Does:
━━━━━━━━━━━━━━━━━━━━━━
- Automatically detects website design using AI/LLM
- Scrapes product data from hyperone, carrefour, and other sites
- Extracts: Name, Price, Discount, Unit, Quantity
- Exports professional Excel reports with statistics

Quick Start (Choose One):
━━━━━━━━━━━━━━━━━━━━━━━
1. DEMO MODE (no API key needed):
   python demo_scraper.py
   
2. VERIFY SYSTEM:
   python verify_system.py
   
3. RUN FULL SCRAPER (needs API key):
   python run_scraper.py
